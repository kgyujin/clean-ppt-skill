# 스타일 확장과 검토 기록

검토일: 2026-10-22

## 작업 범위

5개 스타일의 15장 시안을 제작하고, 기존 12종 레이아웃과 함께 사용할 선택 지침을 보완했습니다. 미리캔버스 공식 목록의 대표 이미지 12개를 직접 확인했습니다. 이는 내부 페이지 전체나 유료 원본을 검토한 기록이 아닙니다. 자세한 출처와 반영 원리는 [레퍼런스 기록](../references/reference-research.md)에 있습니다.

## 실제 협업 방식

- Claude Code: 도구 없는 첫 검토에서 5가지 구성 문법과 발표자·청중·디자이너·근거 관점을 제안했습니다.
- Claude Code: 두 번째 검토에서는 Read 도구로 5개 스타일의 실제 미리보기 PNG를 열고 페이지별 문제를 지적했습니다. 세 장을 합친 축소판이므로 실제 폰트 크기와 PowerPoint 줄바꿈을 측정한 검토가 아닙니다.
- Codex: 장면과 네이티브 PPTX, 보조 PDF를 제작하고 지적 사항을 수정한 뒤 다시 렌더링했습니다.
- 별도 Codex 작업자: 레이아웃 검사기, README 구성, 짧은 프롬프트 적용 시험을 나누어 진행했습니다.

역할별 에이전트 검토이며 실제 사용자 만족도 조사나 모든 청중의 동의가 아닙니다. 수정 후 최종본을 Claude가 다시 승인했다고 주장하지 않습니다.

## 지적과 반영

| 지적 | 반영 |
| --- | --- |
| 제목과 큰 표지 문구가 같은 위계로 경쟁 | editorial·studio 표지의 문서명을 작게 구분하고 중심 문구 강조 |
| editorial 비교 제목과 요약 표현 불일치 | 문서 탐색 변화로 통일하고 열 시작 높이 정리 |
| 순서가 있는 도식에 방향 표시 누락 | editorial 단계 사이 화살표 추가 |
| 계획 수치가 실적처럼 보일 수 있음 | 시험 계획과 수치 상태를 가까이 표시 |
| warm의 사람/도구 열이 동일 | 사람의 검토 영역 배경을 구분하고 역할 제목 유지 |
| 시험 이후가 2주 일정에 섞임 | 후속 검토로 제목 수정하고 종료 이후 구분선 적용 |
| technical 도식이 꺾여 읽기 어려움 | 가로 순서로 재배치하고 별도 방향 설명 제거 |
| 제외 범위를 제목에 쓰고 표에는 누락 | 권한 문서 제외 행 추가 |
| executive의 동일한 미측정 열 반복 | 상태를 부제에서 한 번 안내하고 질문 영역 확대 |
| 모든 스타일이 비슷해 보임 | studio는 넓은 타이포, warm은 수직 일정, technical은 탐색 레일, executive는 요약과 검토 행으로 구분 |

Claude의 제안을 그대로 적용하지 않은 부분도 있습니다. 모든 이미지를 텍스트로만 만들기, 표 3열 제한, 빈 공간의 고정 비율 같은 규칙은 자료에 따라 부적합하므로 강제하지 않았습니다. 입력에 없는 승인·반복 경로도 추가하지 않았습니다.

최종 개별 PNG 15장 검토에서 studio 비교 행의 기준선 차이를 추가로 발견해 241/383px로 맞췄습니다. 수정 후 PPTX·PDF·PNG를 다시 생성하고 구조 검사와 해시 기록을 갱신했습니다.

## 짧은 프롬프트 시험

[팀 회고 입력](../examples/short-prompt/brief.md)에 `$clean-ppt 이 자료로 5분 발표자료 만들어줘.`를 적용했습니다. 별도 작업자가 스킬과 예제를 읽고 warm 스타일을 선택해 실제 3장 PPTX, 보조 PDF와 메모를 작성했습니다.

원문에 있던 회의록 중복, 공유 양식 제안, 미실행·미실측 상태를 유지했습니다. 검색 서비스 예제의 30개 문서, 3명, 2주, 권한 문서 등의 문구는 들어가지 않았습니다. 5분은 토의 시간을 포함한 계획이며 실제 발표 시간을 측정하지 않았습니다.

별도의 검색 서비스 구조 요청에서는 technical 선택과 3장 구성 계획만 확인했습니다. 이 두 번째 요청을 새 PPTX 제작 완료 사례로 세지 않았습니다.

## 검증과 한계

- 단위 테스트 9개 통과: 표 편집성, 너비 오류, 글자 넘침, 대비, 겹침, 폰트 미지정 처리.
- 5종 시안 15장과 짧은 요청 예제 3장: 지정한 Pretendard의 글자 폭 기준 레이아웃 오류 0, 경고 0.
- PPTX는 네이티브 글자와 도형, 발표 메모를 포함합니다. 실제 생성 파일의 해시와 페이지 수는 [산출물 기록](artifact-manifest.json)에 있습니다.
- PDF·PNG는 같은 장면을 ReportLab로 별도 렌더링한 보조 출력입니다. PowerPoint에서 직접 내보낸 파일이 아닙니다.
- 실제 PowerPoint/Google Slides 앱의 렌더링, 다른 컴퓨터의 글꼴 대체, 사용자 만족도는 미검증입니다.

오류 0건은 이 검사 범위에서 발견된 문제가 없다는 의미입니다. 미적인 완성도나 모든 환경의 정확한 출력을 보증하지 않습니다.
