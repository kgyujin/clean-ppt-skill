# 발표 요청 양식

```text
$clean-ppt 아래 조건으로 발표자료를 만들어줘.

주제:
청중:
발표 시간:
원하는 장수: 내용에 맞게 제안
핵심 내용:
첨부 자료:
반드시 유지할 수치와 조건:
원하는 스타일: 기본 파란 비즈니스 스타일
참고 디자인: URL 또는 이미지
필요한 파일: PPTX, PDF, 전체 미리보기, 발표자 노트
저장 위치:
```

Claude Code에서는 첫 줄의 `$clean-ppt`를 `/clean-ppt`로 바꿉니다. 알 수 없는 항목은 생략해도 됩니다.

## 기본 구성 예시

| 순서 | 내용 | 배치 후보 |
| --- | --- | --- |
| 1 | 주제와 핵심 문제 | 제목과 짧은 요약 |
| 2 | 기존 방식과 개선 방식 | 같은 항목의 비교표 |
| 3 | 작동 순서 | 방향이 분명한 흐름도 |
| 4 | 확인한 결과 | 실제 수치 또는 실행 화면 |
| 5 | 적용 범위와 한계 | 조건별 정리 |
| 6 | 다음 단계 | 일정과 확인할 항목 |

장수와 순서는 발표에 맞게 바꿉니다. 측정값이 없다면 결과 수치를 만들지 않고 구현 화면이나 확인할 항목을 보여줍니다.
