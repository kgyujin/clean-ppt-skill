# 레이아웃 선택 가이드

각 JSON은 한 장짜리 원본입니다. 제목, 본문과 발표 메모를 바꾸고 제작기로 PPTX를 생성합니다. 예제 수치는 실제 성과로 재사용하지 않습니다.

| 유형 | 적합한 내용 | 원본 |
| --- | --- | --- |
| 표지 | 업무 개선 발표 | [JSON](v9-cover.json) |
| 개선 전후 | 기록 방식의 변화 | [JSON](v9-comparison.json) |
| 업무 흐름 | 현장 업무 흐름 | [JSON](v9-process.json) |
| 수치 비교 | 검수 시간과 입력 누락 | [JSON](v9-results.json) |
| 적용 범위 | 적용 범위와 한계 | [JSON](v9-scope.json) |
| 다음 단계 | 다음 단계 | [JSON](v9-next-step.json) |
| 시험 일정 | 시험 일정 | [JSON](v9-timeline.json) |
| 검토 항목 | 확인할 항목 | [JSON](v9-checklist.json) |
| 도입 판단 | 도입 판단 | [JSON](v9-decision.json) |
| 서비스 구조 | 서비스 구성 | [JSON](v9-architecture.json) |
| 조건 분기 | 검수 결과의 분기 | [JSON](v9-branch.json) |
| 코드 설명 | 코드와 동작의 연결 | [JSON](v9-code.json) |

[전체 PPTX](../examples/layout-gallery/deck.pptx) · [전체 PDF](../examples/layout-gallery/deck.pdf)

표지는 큰 제목과 오른쪽 안내 영역을 사용합니다. 본문은 비교 열, 수평 흐름, 일정, 행 중심 목록 등 내용에 맞게 바꿉니다. 긴 문장을 그대로 넣고 글씨만 줄이지 않습니다.
