# 미리캔버스 레퍼런스 읽기

출발점은 공식 프레젠테이션 목록이다.
- https://www.miricanvas.com/ko/template/presentation?purpose=WEB
- https://www.miricanvas.com/ko/templates
- https://help.miricanvas.com/hc/ko/articles/4404308084249

2026-10-22 확인한 공식 목록에는 비즈니스 기획서, 보고서, 영업용 비교 자료 등 여러 유형이 있다. 이 기록은 미래의 개별 템플릿 접근 가능성을 보장하지 않는다. 실제 제작 시 사용 가능한 브라우저나 검색으로 현재 보이는 자료를 확인한다.

1. 발표 목적과 가까운 표지 한 개, 비교나 표가 있는 본문 한 개, 과정이나 사진이 큰 본문 한 개를 우선 본다.
2. 템플릿이 제공되면 전체 축소판과 개별 본문을 모두 본다. 색만 수집하지 않는다.
3. `관찰한 페이지/이미지 | 제목 기준선 | 본문 비율 | 밀도 | 적용할 원리`로 기록한다. URL만 여러 개 모으는 것을 디자인 분석으로 대신하지 않는다.
4. 원리가 맞는지 이번 자료의 내용으로 확인한다. 기능 설명에 영업 가격표를 억지로 씌우지 않는다.
5. 저작권 표시, 로고, 사진, 프리미엄 요소나 템플릿 파일을 통째로 가져오지 않는다. 이용 가능한 사용자 자산이나 직접 만든 네이티브 도형으로 배치를 구현한다.
6. 사이트에 접근하지 못했다면 그 한계를 기록하고 로컬 레퍼런스와 기본 디자인 기준으로 진행한다. 보지 않은 양식을 참고했다고 주장하지 않는다.

사용자 요청에 원본 템플릿 사용이 포함되면 해당 자산의 이용 조건과 권한을 확인한다. 계정 로그인, 다운로드, 공유 설정 변경은 별도의 도구 정책과 사용자 권한 범위 안에서 진행한다.
