# 본문 레퍼런스 분석과 적용

2026-10-22, 미리캔버스 공식 도움말의 공개 본문 이미지 3개를 직접 열어 보았습니다. 편집기나 유료 템플릿을 사용한 것은 아닙니다. 원본 이미지와 자산은 배포물에 포함하지 않습니다.

## 제작 순서

공식 AI 프레젠테이션 안내는 주제 입력, 테마 선택, 개요 확인, 생성과 편집의 순서를 소개합니다. 이를 스킬에서는 자료 확인 → 본문 구조 선택 → 실제 내용으로 두 장 제작 → 축소판과 개별 페이지 검토 → 전체 확장으로 적용합니다. 자동 생성 자체가 디자인 품질을 보장한다고 해석하지 않습니다.

[공식 제작 흐름 안내](https://www.miricanvas.com/ko/features/ai-presentation-maker)

## 새 시안의 설계 결정

- 비교: 세 열의 역할을 고정했습니다. 개선 열만 면으로 묶고 제목과 설명의 기준선을 맞췄습니다.
- 과정: 네 단계의 가로 경로 아래에 두 갈래 결과를 놓았습니다. 화살표를 텍스트 위로 지나가게 하지 않았습니다.
- 화면: 본문 왼쪽 약 2/3에 직접 작성한 가상 UI를 넣었습니다. 오른쪽에는 발표자가 짚을 두 항목을 배치했습니다.
- 공통: Pretendard, 흰 바탕, 단일 파란 강조색, 64px 좌우 기준선을 유지했습니다. 그라데이션과 반복 장식은 사용하지 않았습니다.

모든 예제 문구는 독립적으로 작성했습니다. 미리캔버스 원본 양식·이미지·로고의 재배포가 아닙니다. 예제는 실제 구현과 측정 결과를 주장하지 않습니다.

## 검토 기준

청중: 비교의 각 행을 가로로 읽을 수 있는지, 화면의 본문이 읽히는지 확인합니다.
발표자: 과정은 왼쪽에서 오른쪽으로, 화면은 질문에서 답변과 출처로 설명합니다.
디자인: 제목 기준선, 행 높이, 글자 대비와 간격을 확인합니다.
근거: 가상 UI 표시를 유지하고 실제 자료로 교체할 때 기능과 경로를 다시 확인합니다.

보조 PDF와 PNG는 같은 장면 데이터에서 렌더링합니다. PowerPoint 앱의 PPTX 렌더 결과와 동일하다고 보장하지 않습니다.
