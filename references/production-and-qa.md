# 제작과 검수

## 개체와 정보
- PPTX 본문과 제목은 실제 텍스트로 유지한다. 한국어 테마의 East Asian 글꼴도 동일하게 지정한다.
- 표, 막대와 꺾은선 등 지원 차트는 해당 편집기의 표와 차트 개체를 사용한다.
- 원본 사실, 미확인 주장과 설명용 예시를 분리한다. 디자인 요청은 누락된 실적을 지어낼 허가가 아니다.
- 도형 안 텍스트의 내장 여백을 통제한다. 여백이 다른 텍스트 상자를 눈대중으로 맞추지 않는다.

## 도식
연결선은 내용의 관계다. 화살촉이 도착 개체를 향하는지, 복귀 선은 거꾸로 향하지 않는지, 반복을 끝내는 조건이 있는지 확인한다. 사선의 좌표를 최소값으로 바꾸고 화살표만 달면 기울기가 뒤집힐 수 있으므로 방향을 보존한다. 제공 보조 제작기는 오류를 줄이기 위해 수평·수직 선만 지원한다. 사선이나 곡선이 필요하면 지원 도구로 올바르게 구현한다.

## 캡처
대사와 결과, 수치가 원본과 같은지 먼저 확인한다. 필요한 두 영역을 잘라 각각 읽히게 배치한다. 픽셀 수뿐 아니라 실제 글자 크기로 읽어 본다. 표시폭 600px이라면 원본 900~1200px를 목표로 하되 없는 해상도를 보간해서 만들지 않는다. 원본이 작으면 재촬영하거나 제약을 알린다. 비율을 늘려 사람이나 화면이 납작해지지 않게 한다.

## 자동 검사와 수동 검사
`audit_deck.py`는 장면 경계, 이미지 비율과 픽셀 밀도, 텍스트 크기·폰트 불일치, PPTX XML과 노트 수 등을 확인한다. 이 도구가 본문을 실제로 읽고 내용 정확성이나 모든 글자 겹침을 증명하는 것은 아니다. 경고를 검토해 의도된 것인지 기록한다. 텍스트 줄바꿈은 실제 글꼴과 렌더를 함께 확인한다.

전체 축소판에서는 같은 틀의 과도한 반복, 빈 공간과 정보 밀도, 장별 시각적 무게를 본다. 개별 페이지에서는 글자 크기, 정렬, 대비, 캡처와 표 안의 작은 글자, 선의 끝과 강조 위치를 읽는다. 수정 후 최신 파일을 다시 본다.

## 출력 차이
PPTX 직접 내보내기가 가장 확실하다. 보조 PDF 생성은 같은 장면의 검토용 출력이며 실제 앱 출력이 아니다. Google Slides 이미지 복사본은 서체 외형 유지에 유리하지만 텍스트를 직접 고치는 원본이 아니다. 앱별 검증과 편집 가능성을 구분해 전달한다.

## 기록
최소 기록은 사용한 자료와 수치, 레퍼런스 관찰, 장별 메시지와 배치, 검사 결과, 실제로 확인한 앱이다. 사용자 발표 화면에 이 제작 정보를 억지로 넣지 않는다. 확인하지 않은 앱이나 미적 품질을 검사 통과로 포장하지 않는다.

## 전달 환경과 버전
테마에 Pretendard를 지정하는 것과 폰트 파일을 PPTX에 임베딩하는 것은 다르다. 제작에 사용한 실제 폰트와 전달 환경의 설치 여부, 허용된 임베딩 방식이 있는지 확인한다. 라이선스를 확인하지 않은 폰트 파일은 스킬에 묶지 않는다. 최종 파일 해시와 페이지 수를 기록하고, 실제 앱이 없으면 보조 PDF 검사와 PPTX 앱 렌더 미검증을 구분한다.
